Layer Descriptions

  • Application Layer: Simple API, Client API, Agent Framework

  • Extension Layer: Guardrails, MCP, Skills, Knowledge/RAG, Evals

  • Infrastructure Layer: hooks/events, scheduling/triggers, HITL, pipeline server, Temporal worker, CLI

  • Backend Layer: LiteLLM calling via TIP.ai gateway to cloud providers
