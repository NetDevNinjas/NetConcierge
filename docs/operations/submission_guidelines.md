# Steps below to submit your Codefest 4.0 project

- Download the Codefest 4.0 PowerPoint project template.
- Create a folder in your OneDrive using your team name as the folder title.
- Upload all project artifacts (presentation and any supporting materials) into this folder.
- Share the folder with the Codefest organizers:
  - Lisa Roberts - lisa.roberts2@marriott.com
  - Achint Choudhry - achint.choudhry@marriott-sp.com
  - Lak Tripuraneni - lakshmikant.tripuraneni@marriott.com
  - Devesh Arora - devesh.arora@marriott.com
- Send a submission confirmation email to codefest@marriott.com that includes a link to your shared folder by Friday, May 22 - 2 PM (ET).
  - This email will serve as your official confirmation of submission.
