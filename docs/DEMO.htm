The Problem

WiFi outages are invisible until they become complaints

A hotel guest's WiFi drops at 9 PM before an early morning presentation. Under the traditional model, they wait, they call the front desk, they explain the issue to a non-technical concierge who files a ticket, an engineer checks in the morning — and the guest checks out furious. The hotel learns about the fault from a one-star review.

❌ Traditional Response

  • Fault discovered via guest complaint (avg 15–30 min delay)
  • Manual ticket filed; engineer dispatched
  • No compensation unless guest escalates
  • Guest must re-explain issue multiple times
  • Resolution takes 30–120 minutes
  • Outage duration never formally tracked

✓ NetConcierge Response

  • Fault detected in ≤ 3 seconds by continuous monitoring
  • WiFi refund + bar credit issued before guest notices
  • AI diagnoses and fixes most faults in under 60 seconds
  • Guest receives proactive notification and compensation
  • Full diagnostic history logged automatically
  • Human operator paged only when software cannot resolve

Agent Intelligence

The LLM decision tree

The agent is not scripted — it reasons about the current state using a large language model and chooses the appropriate tool at each step. It can handle single-path failures, dual-path outages, packet loss, high latency, and container-level faults. When it cannot recover, it escalates to a human with full context.

Guest Compensation

Right-sized compensation, automatically

NetConcierge distinguishes between faults it can fix and faults that require human intervention. Compensation scales accordingly — guests are never under-compensated for extended outages, and the hotel never over-compensates for a 40-second blip.

Tier 1 — Immediate

Service Disruption Detected

Issued within seconds of fault detection — always
  • Full WiFi bill refund for the day
  • Complimentary drink or appetizer at the lobby bar
  • Issued automatically, no LLM required
  • Guest receives perks even if fault is resolved in 30 seconds

Tier 2 — Escalation

Agent Could Not Resolve

Issued only when all automated recovery fails
  • LLM reviews guest loyalty profile and fault context
  • Personalised recommendation from a menu of options
  • Examples: complimentary dinner, spa credit, room upgrade, loyalty bonus
  • Stacks on top of Tier-1 — both are issued
  • Human operator paged with full diagnostic history

Worst Case

When the AI can't fix it — human escalation with full context

For persistent hardware faults that software cannot resolve, NetConcierge exhausts every available tool, then pages a human operator with a complete diagnostic record and an LLM-generated personalised compensation recommendation. The operator arrives with everything they need to act immediately.

Technical Architecture

How the system is built

NetConcierge runs entirely inside Docker Compose on a single EC2 instance. All components communicate over isolated Docker bridge networks — the simulated hotel network is real infrastructure, not mocked responses.

Live Perk Issuance
